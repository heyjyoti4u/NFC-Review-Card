⭐ Review Card Maker

Google review link daalo → QR code, print-ready card aur NFC tag, sab ek jagah.

1. Details bharo

Google Business Profile → Ask for reviews se link copy karo.

2. Download / Print

Print dialog me Save as PDF chuno, aur print shop ko wahi PDF do. Scale 100% rakho, tabhi card ka size sahi aayega (85.6 × 54 mm).

3. NFC tag me link likho

Sirf Chrome (Android) me chalta hai, NFC ON ho. iPhone ya computer par NFC Tools app use karo (README dekho).
